Introducing Sendly Notification

True Global Reach: Web Push Notifications on Sendly are 100% global and work flawlessly on all major browsers (Chrome, Firefox, Edge, Safari). (Note: Email push is available in select regions).

Sendly Developer Guide & API

Integrating Sendly is effortless. The Sendly Config is a single line of JavaScript you add to your ``. It handles popup permissions, service worker registration, and saves subscriptions automatically.

<!-- Add to your head tag -->
<script src="https://push-notification-server-5tx2.onrender.com/sdk.js" data-api-key="sendly_live_YOUR_API_KEY"></script>
Security First: Crack Signals
Sendly features a built-in security defense. Invalid HTTP requests, failed authentication, or rate limit abuse generate "Crack Signals". If your app accumulates 100 signals, the API key is automatically locked for 48 hours to prevent unauthorized access.

Core API Endpoints

Method Endpoint Description
POST /api/v1/auth/login Login & retrieve session token
POST /api/v1/apps/create Create new app and generate API Key
POST /api/v1/send Broadcast a push or email notification
GET /api/v1/subscribers Retrieve subscriber list
GET /api/v1/analytics/overview Fetch overall performance analytics

Sending a Notification (cURL)

You can interact with Sendly's robust API straight from your server or terminal. Here is how you trigger a global push notification:

curl -X POST https://push-notification-server-5tx2.onrender.com/api/v1/send \
  -H "Content-Type: application/json" \
  -H "x-sendly-key: YOUR_API_KEY" \
  -d '{
    "channel": "push",
    "title": "Hello World!",
    "message": "This is a test notification from HGT Sendly",
    "image": "https://example.com/image.png",
    "button1_name": "Read More",
    "button1_url": "https://henrygolbalindustry.blogspot.com"
  }'
